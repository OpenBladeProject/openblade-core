OpenBlade — бесплатное приложение для области уведомлений Windows на ноутбуках
Razer Blade. Оно позволяет настраивать производительность, вентиляторы, зарядку,
подсветку, дисплей и специальные клавиши без учётной записи Synapse. Профили
автоматически переключаются при питании от сети, USB-C и аккумулятора и продолжают
работать после закрытия окна.

<a id="supported-laptops"></a>
## Поддерживаемые ноутбуки

Для OpenBlade требуется 64-разрядная Windows 11 версии 24H2 или новее.

| Ноутбук | Номер модели |
| --- | --- |
| Razer Blade 16 (2026) | `RZ09-0581` |
| Razer Blade 16 (2025) | `RZ09-0528` |
| Razer Blade 14 (2025), экспериментальная поддержка | `RZ09-0530` |
| Razer Blade 16 (2023), экспериментальная поддержка | `RZ09-0483` |
| Razer Blade 14 (2023), экспериментальная поддержка | `RZ09-0482` |
| Razer Blade 18 (2023), экспериментальная поддержка | `RZ09-0484` |
| Razer Blade 15 Base (начало 2020 года), экспериментальная поддержка | `RZ09-0328` |

Доступные настройки зависят от модели. OpenBlade автоматически включает доступные
настройки на экспериментальных моделях. Сведения о совместимости приведены в
[руководстве пользователя](https://github.com/OSSBlade/openblade-docs), а функции
моделей и инструкции по тестированию — в разделе
[«Экспериментальная поддержка»](docs/ru-RU/experimental-blade-support.md).

Если вашего ноутбука Razer нет в списке, выберите в OpenBlade пункт
**Помочь добавить поддержку**. Сохраните отчёт об идентификации, затем следуйте
[руководству Synapse Observer](https://github.com/OpenBladeProject/synapse-observer#send-evidence),
чтобы собрать и отправить данные о своей модели.

<a id="features"></a>
## Возможности

- Режимы питания, автоматическая или фиксированная скорость вентиляторов,
  пользовательские кривые вентиляторов и смещение частот графического процессора NVIDIA.
- HyperBoost при питании от полноразмерного сетевого адаптера, с охлаждающей подставкой
  Razer или без неё. Начните с любого поддерживаемого режима питания от сети; при
  выключении функция восстанавливает исходные настройки.
- Ограничения заряда, состояние аккумулятора и отдельные настройки для каждого
  источника питания.
- Эффекты клавиатуры и логотипа на крышке, реактивная подсветка, индикаторы
  отключения звука, а также поддержка файлов Razer `.chroma` и общих пресетов `.oblight`.
- Профили дисплея, управление яркостью, поведение функционального ряда и сочетания
  M1–M5 на слое Fn.
- Изменение порядка показаний датчиков в реальном времени и поиск приложений,
  которые не дают графическому процессору NVIDIA перейти в спящий режим.

У каждого пользователя Windows свои профили и параметры с возможностью импорта и
экспорта. Интерфейс поддерживает английский, упрощённый китайский и русский языки.
Проверка обновлений необязательна; доступны каналы Stable и Nightly.

<a id="install"></a>
## Установка

1. Скачайте `OpenBlade-Setup.exe` из
   [последнего выпуска](https://github.com/OSSBlade/openblade-core/releases/latest).
2. Дважды щёлкните файл и выберите **Установить**. Запускайте его обычным способом:
   установщик запросит разрешение администратора, когда оно потребуется.
   Если .NET 10 Desktop Runtime отсутствует, установщик предложит скачать и установить его.
3. Выберите **Запустить OpenBlade**, чтобы открыть приложение в области уведомлений.

Удалить приложение можно через Параметры Windows > Установленные приложения. Можно
сохранить свои профили или удалить их. Тестовые сборки Nightly могут быть не подписаны,
поэтому Windows может показать предупреждение.

<a id="using-it-with-synapse"></a>
## Совместное использование с Synapse

OpenBlade работает самостоятельно. Если вы хотите сохранить Synapse для других
устройств Razer, сведения о поддерживаемых моделях и инструкции по установке исправления
см. в [Synapse Blade Blocker](https://github.com/OpenBladeProject/synapse-blade-blocker).
Перед совместным использованием OpenBlade проверяет исправление; подробности приведены
в [заметках об установке и совместном использовании](docs/ru-RU/synapse-blade-blocker.md).

Для основных функций дополнительный драйвер не нужен. Стандартное всплывающее окно
яркости Windows на Blade 16 (2025 и 2026) использует собственный драйвер Razer для
соответствующей модели, если он уже установлен. Без него клавиши яркости используют
всплывающее окно OpenBlade. См. [руководство по драйверу яркости](docs/ru-RU/razer-brightness-driver-package.md).
