# 基于已审核来源的 Blade 支持

[English](../experimental-blade-support.md) | 简体中文 | [Русский](../ru-RU/experimental-blade-support.md)

以下二十个笔记本系列基于已审核的对应型号 Synapse 和上游来源获得正式支持。
OpenBlade 的稳定版和预发布版都会自动识别这些型号。实机验证按型号和功能
单独跟踪；基于来源的支持不代表已完成全部实机测试。RZ09-0581 和 RZ09-0528
仍保留各自已通过实机验证的支持状态。下文中的限制和仍属实验性的功能继续适用。

停止/自动风扇控制支持八个型号系列，适用于 USB-C 供电的平衡模式。
具体型号和 EC 版本见[覆盖情况](../fan-stop-model-coverage.md)。
七个新增系列的固件控制流程均已单独审核，尚未经过实机测试。
此功能要求系统已安装经过审核的 InpOut 驱动；PawnIO 仅用于读取 CPU 温度。

### GPU 频率偏移

RZ09-0529 和 RZ09-0530 在确认使用外部电源时（包括低功率适配器）提供 GPU 核心和
显存频率偏移；电池供电时隐藏该功能，并拒绝新的偏移。Synapse 为产品 711 和 709
启用 NVIDIA 超频面板，核心范围为 -1000 至 400 MHz，显存范围为 -1000 至 3000 MHz，
步长 1 MHz；已固定的 Synapse 文件列在各型号的诊断证据中。OpenBlade 通过 NVIDIA
驱动写入，不经过笔记本固件，并取该范围与驱动报告范围的交集。适配器功率低于
推荐值时，Synapse 也会隐藏该面板；OpenBlade 沿用与 RZ09-0581 和 RZ09-0528 相同的
外部电源规则，因此使用低功率适配器时仍可调整偏移。切换到电池供电后，OpenBlade
停止管理偏移，但不会将其恢复为 0。如果 GPU 写入中断，供电方式改变时 OpenBlade
会先从驱动读取偏移。如果无法读取驱动，OpenBlade 不写入偏移，并继续管理偏移。
供电方式改变会清除“未确认更改”提示，OpenBlade 会在下次使用 GPU 时再次读取驱动。

Synapse 按产品应用该范围，不检查 GPU 名称。OpenBlade 另加一项检查：笔记本必须只有
一个 NVIDIA GPU，且名称为 `NVIDIA GeForce RTX <name> Laptop GPU`，每次读取和写入
都会重新检查。其他名称、台式机名称或第二个 GPU 都会使该功能不可用。这不是厂商列表。
产品 711 的 VBIOS 更新列表（RTX 5070、5080、5090，按子字符串匹配；
`main.1f8e0c604f19af3ea24c.js`，SHA-256
`C8C0C794D6D01867CD9C6020869808428B81CB98AE297E46EC700F3B935BFF7E`）可佐证
RZ09-0529 的配置；产品 709 未列出 GPU。RZ09-0581 和 RZ09-0528 仍只允许
RTX 5090 Laptop GPU。此支持基于已审核来源，尚待实机验证。

使用这些功能前，请关闭 Synapse。如果需要保留 Synapse，请先查看
[Synapse Blade Blocker](synapse-blade-blocker.md) 支持的型号，再按说明应用补丁。

- Blade 16 (2023) 的固定风扇转速可设为 2,000–5,000 RPM，
  Blade 14 (2023) 为 2,200–5,000 RPM。选择自动模式后，风扇由固件接管。
  Blade 18 在平衡模式下提供一个 2,200–3,800 RPM 滑块，同时控制两个风扇，电池供电时也可使用。

  如果无法读取地区，映射存在地区差异的按键暂不能触发灯效。
- Blade 18 (2023) 提供实验性的 [Synapse 默认 Fn 快捷键](../blade18-fn-decoder.md#default-shortcuts)：
  性能、刷新率、触摸板、F1–F12、方向键和 Delete。解码和动作已有源码依据，仍需在笔记本上测试。
  仅连接笔记本内置键盘时，OpenBlade 才会处理这些 Fn 快捷键。
- Blade 14 (2023)、Blade 16 (2023) 和 Blade 16 (2024) 提供 HyperBoost，需要使用足功率电源，连接或不连接 Razer Laptop Cooling Pad 均可。
  Blade 16 (2023) 需要 MCU 固件 1.5.0.0 或更新版本，Blade 16 (2024) 需要 1.3.0.0 或更新版本。
  Blade 14 需要 MCU 固件 1.1.1.3 或更新版本。
  与 Synapse 一致，对于 Synapse 按系统 SKU 排除的 Blade 16 配置，OpenBlade 不会启用 HyperBoost，但你仍可以将其关闭。
  使用电池时，HyperBoost 结束后会切换到 Balanced；重新接通电源后，会恢复接通电源时的模式。
  Blade 18 (2023) 仍只能读取状态；更改性能设置前，请先在 Synapse 中关闭 HyperBoost。
- 充电上限每次可调整 1%，设为 100% 时会关闭充电保护。
  Blade 15 不支持充电上限。Blade 18 和 Blade 14 (2025) 在成功读取状态后支持实验性的临时充满；开启时需要已启用充电上限，且不能覆盖其他 Power Mode Control 选项。在 Blade 18 (2025) 和 Blade 14 (2025) 上，Synapse 可能会随 Windows HDR 开启局部调光（属于这些选项之一）。如果 Synapse 正在运行，请关闭 Windows HDR，再关闭 Synapse，然后重试。

## 仅显示的 Synapse 功能

OpenBlade 会在诊断信息中报告以下 Synapse 功能。Synapse 通过其自带的本机组件更改这些设置，因此 OpenBlade 不会更改它们。请在 Synapse 中调整这些设置。

| 功能 | 笔记本 | Synapse 提供的设置 |
| --- | --- | --- |
| CPU 功耗上限 | `RZ09-0508`、`RZ09-0530` | 自定义模式下 45–95 W |
| CPU 功耗上限（PL1、PL2、时间窗口） | `RZ09-0483`、`RZ09-0484`、`RZ09-0510`、`RZ09-0509`、`RZ09-0529` | PL1 1–190 W，PL2 1–200 W 并带开关，步长 0.125 W；时间窗口 1–128 秒；默认 PL2 160 W、PL1 120 W、56 秒 |
| 游戏模式 GPU 超频 | `RZ09-0300`、`RZ09-0351`、`RZ09-0328` | 游戏模式会附加笔记本中存储的 GPU 和显存超频 |
| 局部调光 | `RZ09-0530`、`RZ09-0528`、`RZ09-0581` | 跟随 Windows HDR 设置 |

Intel 型号所列的范围来自 RZ09-0510、RZ09-0509 和 RZ09-0529 的设置页面。RZ09-0483 和 RZ09-0484 的默认值相同，但其各自的范围尚未审阅，因此诊断信息将其报告为未知，而不是沿用其他型号的范围。在 RZ09-0482 上，Synapse 的功耗控件调整的是 CPU 曲线优化器，因此未列出功耗上限。

### Blade 16 (2024) 和 Blade 18 (2024) 的局部调光

在 `RZ09-0510` 和 `RZ09-0509` 上，如果笔记本报告为 mini-LED 屏幕且局部调光已开启，“显示”页面会显示**局部调光**和**关闭**按钮。OpenBlade 只能关闭局部调光。最大风扇或 Synapse 自身的 CPU boost 设置开启时不会关闭（这不是 OpenBlade 自定义模式中的 CPU Boost 等级）。卡片会注明是哪项设置：请在 Synapse 中将其关闭，然后重试。局部调光开启时，OpenBlade 的最大风扇和平衡模式更改也会等待，因此如果两者都开启，请在 Synapse 中更改其中一项。每次更改都会通过新的读回确认。如果无法确认结果，笔记本控制会暂停，直到你检查屏幕并选择**恢复笔记本控制**。

固定的 Synapse 文件见[源代码审阅](../../evidence/source-reviewed-blades/2026-11-20-observed-features-and-local-dimming.json)。实机验证尚未完成。

<a id="send-a-useful-test-report"></a>

## 提交测试报告

原有五款型号还支持 [SnapTap](../snap-tap.md#supported-driver-profiles)，可选择 Windows 钩子，
或使用各型号已审核的 Razer 键盘筛选驱动和共享控制驱动。Razer 后端在这些型号上仍属实验性支持。
如果缺少驱动栈，请选择**安装驱动**。OpenBlade 会先检查 Windows 更新；
仅当首次搜索成功且没有合适的驱动更新时，才可改用该型号已固定版本的驱动包。
不需要先安装 Synapse。SnapTap 的实机验证与这些型号的固件控制验证相互独立。

1. 安装完整的[当前版本](https://github.com/OpenBladeProject/openblade-core/releases)。
   在**关于**中记录版本和检测到的型号。
2. 使用**关于 → 导出诊断信息**保存测试前的诊断 ZIP。
3. 试着更改一项设置。记下供电方式、原来的设置和想要设置的值、操作时间和实际观察到的结果。
4. 恢复原来的设置，确认恢复结果，再次导出诊断信息。
5. 检查 ZIP，将其和观察结果附到
   [支持测试议题](https://github.com/OpenBladeProject/openblade-core/issues/741)。

测试睡眠和唤醒时，请留在电脑旁，以便唤醒电脑并检查结果。
报告只保存在本机，是否分享由你决定。

<a id="if-controls-pause"></a>

## 控制功能暂停时

先导出诊断，再在通知中选择**恢复笔记本控制**。
OpenBlade 会检查笔记本并读取当前设置。
检查通过后，请重新选择要应用的设置。OpenBlade 不会自动重试之前的操作。
如果要恢复灯光，请重新选择灯光设置，或修改当前配置中的灯光选项。
检查失败时，控制功能会继续暂停。

仅性能或风扇操作需要恢复时，无须成功读取无关的充电上限或临时充满状态。
只有可能已发送的临时充满更改，才需要重新读取该设置。
尚待确认的电池操作仍需各自读取确认。

在 RZ09-0529 和 RZ09-0530 上，控制暂停期间已应用的 GPU 频率偏移保持不变；新的偏移
（包括恢复为 0）会等到控制恢复后再应用。如果恢复检查无法确认被中断更改的偏移，
OpenBlade 会在下一次更改 GPU 或性能设置时重新发送。

协议限制、诊断字段和上游来源见[实现参考](../experimental-blade-reference.md)。

Blade 18 还支持通过经典 Keyboard .chroma 文件导入逐键颜色和动画序列，
以及主机渲染的单色、双色 Breathing 和向左 Wave。Gaming Mode 可在
OpenBlade 运行时屏蔽 Windows 键和 Alt+Tab，作用于所有键盘。
详见[灯光说明](../blade18-spatial-lighting.md#per-key-colors-and-playback)和
[来源核查](../blade18-source-feature-recovery.md)。

Blade 18 在成功读取状态后还支持实验性的开机灯光动画开关，每次修改后都会重新读取确认。

Blade 18 进入 Custom 前会先确认风扇已切换为自动，返回支持手动风扇的模式时可恢复保存的风扇设置。
Blade 16 (2023) 和 Blade 14 (2023) 进入 Custom 或更改 CPU/GPU 档位时，会保留已确认的固定风扇转速。
