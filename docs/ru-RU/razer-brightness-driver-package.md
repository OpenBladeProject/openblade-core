# Пакет драйвера яркости Razer

[English](../razer-brightness-driver-package.md) | [简体中文](../zh-CN/razer-brightness-driver-package.md) | Русский

OpenBlade может использовать уже установленный подписанный стек Razer Consumer Control
на любой из двух перечисленных ниже моделей Blade 16. Тогда изменением яркости и
стандартным всплывающим окном управляет Windows. В разделе «О программе» > «Сведения об
устройстве» указано, доступно ли управление через проверенный драйвер именно этой модели.
Если он недоступен, клавиши яркости продолжают использовать WMI и всплывающее окно
OpenBlade.

Обычный установщик OpenBlade не устанавливает и не удаляет драйверы Razer.

<a id="runtime-hardware-scope"></a>
## Поддерживаемое оборудование

Два модуля управления яркостью через Windows используют отдельные стеки драйверов
для своих моделей.
Перед использованием любого из них OpenBlade проверяет полную иерархию устройства,
имя службы и закреплённые хеши драйверов:

| Ноутбук | USB PID | Служба устройства |
|---|---|---|
| Razer Blade 16 (2026), RZ09-0581 | `02E0` | `RzDev_02e0` |
| Razer Blade 16 (2025), RZ09-0528 | `02C6` | `RzDev_02c6` |

Ни один стек не является универсальным для ноутбуков Razer Blade. Стек RZ09-0581
содержит четыре подписанных INF для конкретной модели и общий пакет управления:

| Пакет | Точное соответствие оборудованию | Назначение |
|---|---|---|
| `rzdevu_02e0_dkm.inf` | `USB\VID_1532&PID_02E0&MI_01` | Фильтр физического устройства и перечислитель виртуальных устройств |
| `rzdevu_02e0_vcon.inf` | `RZVIRTUAL\VID_1532&PID_02E0&MI_00&COL03` | Виртуальное устройство Consumer Control |
| `rzdevu_02e0_kbd.inf` | `HID\VID_1532&PID_02E0&MI_01&COL01` | Фильтр коллекции клавиатуры |
| `rzdevu_02e0_mou.inf` | `HID\VID_1532&PID_02E0&MI_02` | Фильтр коллекции мыши и перечислитель устройства управления |
| `rzcommonu.inf` | `RAZER\DeviceContol` | Общее дочернее устройство управления Razer |

Последний идентификатор записан как `DeviceContol` в подписанном INF Razer. Допущенный
`rzcommonu.inf`, SHA-256
`DD3C8D65C7C3CCF2093FE70FB21FB8DC724E837880566BAE629B3104A5B1B37B`,
дословно содержит `%RzCommon.DeviceDesc% = RzCommon_Device,RAZER\DeviceContol`.
Универсальный компонент RzCommon не делает весь стек универсальным. Остальные четыре
пакета, служба `RzDev_02e0`, имя двоичного файла и их каталоги относятся только к PID
`02E0`. Изменение INF для другого PID нарушит подпись его каталога и не докажет, что
двоичный файл поддерживает это оборудование.

RZ09-0528 использует собственный подписанный стек Razer, когда тот уже установлен:
`rzdevu_02c6_{dkm,vcon,kbd,mou}.inf` со службой `RzDev_02c6`, той же сборкой
`RzCommon.sys` и той же структурой устройств `RZCONTROL`/`RZVIRTUAL` на PID `02C6`.
OpenBlade закрепляет SHA-256 файла `RzDev_02c6.sys`
`307940C7C5AB537F19F0A33ADA592D2D6DE5ECADB13D748019A8F0E13816BA82` и проверяет
каждый идентификатор только по PID `02C6`. Средства экспорта и запись каталога в этом
руководстве относятся только к `02E0`; OpenBlade не включает ни один из стеков в
комплект. Для любой другой модели требуется собственный перечень подписанных пакетов
и аппаратная проверка.

Страницы поддержки Razer:

- [Razer Blade 16 (2026), RZ09-0581x](https://mysupport.razer.com/app/answers/detail/a_id/20585/)
- [Поддержка BIOS Razer Blade 16 (2025), RZ09-0528x](https://mysupport.razer.com/app/answers/detail/a_id/15235/)

Экспортированный архив RZ09-0581, его очищенный манифест и связывающая их запись выпуска
находятся в отдельном репозитории
[`blade-driver-catalog`](https://github.com/OSSBlade/blade-driver-catalog) вместе с
инструкциями по экспорту драйверов других устройств Razer без изменения системы. Каталог публикует
архив как предварительный выпуск; чистая установка ещё не проверена. Однократный запуск
Synapse устанавливает тот же стек. Запись в каталоге документирует собранные данные, но не означает поддержку в
OpenBlade. До допуска в ядре для каждой модели необходимо отдельно проверить работу
программы и оборудования.

<a id="export-the-admitted-rz09-0581-package"></a>
## Экспорт допущенного пакета RZ09-0581

Скрипт `build/Export-RazerBrightnessDriverPackage.ps1` с помощью Windows PowerShell 5.1
создаёт точную копию пакетов для локального использования на компьютере, где уже установлен проверенный стек. Он
находит каждый установленный пакет по хешу опубликованного INF независимо от его
локального имени `oem###`, вызывает Windows `pnputil /export-driver`, а затем проверяет
полный пакет из трёх файлов, хеши SHA-256 и аппаратные подписи Microsoft. Результат
должен находиться за пределами репозитория.

Файл `manifest.json` архива использует тип манифеста
`OpenBlade.RazerDriverPackageArchive`. Его поле `catalogReference` указывает
`OSSBlade/blade-driver-catalog` и
`devices/rz09-0581/1532-02e0/1.0.0.78-1.0.0.76/manifest.json`. Оно намеренно не
включает хеш манифеста каталога, поскольку каталог записывает внешний хеш архива пакета.
Проверенная аттестация выпуска связывает путь и SHA-256 манифеста каталога с именем и
SHA-256 ресурса архива, без взаимного включения хешей этих двух файлов.

```powershell
.\build\Export-RazerBrightnessDriverPackage.ps1 `
    -OutputDirectory C:\tmp\Razer-02E0-Driver-Stack-1.0.0.78-1.0.0.76
```

Полученный детерминированный ZIP содержит пять исходных пакетов Razer: нижний фильтр
физического USB-устройства, функциональный драйвер виртуального Consumer Control,
драйвер устройства управления и фильтры коллекций клавиатуры и мыши. На встроенные
зависимости HID Windows ссылаются исходные INF, и они не копируются. Созданные файлы
PNF и экземпляры устройств конкретного компьютера исключены.

Не устанавливайте пакет на другую модель Blade и не ослабляйте точные проверки
устройства и двоичного файла OpenBlade, чтобы заставить его загрузиться.

<a id="native-windows-installation-path"></a>
## Установка штатными средствами Windows

Windows включает PnPUtil для подготовки подписанных пакетов в Driver Store и их
установки на соответствующие устройства. Microsoft описывает `/add-driver`, `/install`,
`/subdirs` и `/reboot` в
[справочнике команд PnPUtil](https://learn.microsoft.com/en-us/windows-hardware/drivers/devtest/pnputil-command-syntax).

Приведённая ниже последовательность предназначена для проверки на чистой, допускающей
восстановление системе RZ09-0581. Это ещё не инструкция по установке для конечного
пользователя. Стек фильтрует пути встроенных клавиатуры и мыши, перезапускает части
дерева USB-устройств и может потребовать перезагрузки. Используйте питание от сети,
подключите внешние USB-клавиатуру и мышь и до начала проверки убедитесь, что доступ для
восстановления работает.

Перед первым изменением проверьте целевое устройство и пакет в окне PowerShell с
повышенными правами:

1. `HKLM:\HARDWARE\DESCRIPTION\System\BIOS` должен сообщать Razer в качестве
   производителя и `Blade 16 - RZ09-0581` в качестве `SystemProductName`.
2. Windows должна сообщать об одном подключённом устройстве
   `USB\VID_1532&PID_02E0&MI_01` и одном подключённом устройстве
   `USB\VID_1532&PID_02E0&MI_02`. Остановитесь, если идентичности отсутствуют,
   повторяются или отличаются.
3. Имя ZIP и SHA-256 должны совпадать с проверенной аттестацией выпуска. Та же
   аттестация должна определять манифест каталога по пути в репозитории и SHA-256.
   После извлечения каждый файл должен совпасть с `SHA256SUMS.txt`, а каждая подпись
   INF, CAT и SYS должна быть действительной и выпущенной Microsoft Windows Hardware
   Compatibility Publisher. На компьютере проверки с SignTool используйте
   `signtool verify /kp /c <catalog> <INF-or-SYS>`, чтобы подтвердить принадлежность
   каталогу. Microsoft описывает `/c` в
   [справочнике SignTool](https://learn.microsoft.com/en-us/windows-hardware/drivers/devtest/signtool).

До подготовки любых пакетов создайте журнал за пределами пакета и репозитория. Запишите
идентичность BIOS, подключённые совпадающие экземпляры, вывод
`pnputil /enum-drivers /files`, их текущие привязки и стеки, а также текущее дерево
`RZVIRTUAL` и `RZCONTROL`. Сохраните исходный вывод, а не составленное вручную резюме.

Приведённая ниже вспомогательная функция добавляет в журнал каждую команду PnPUtil,
её вывод и код завершения. Сначала задайте `$packageRoot` и `$journalDirectory`.
Остановитесь после любого ненулевого кода завершения. Не повторяйте команду, если её результат
неясен.

```powershell
$packageRoot = 'C:\path\Razer-02E0-Driver-Stack-1.0.0.78-1.0.0.76'
$journalDirectory = 'C:\path\openblade-razer-driver-journal'
$pnp = "$env:WINDIR\System32\pnputil.exe"
$transcript = Join-Path $journalDirectory 'pnputil-transcript.txt'
New-Item -ItemType Directory -Path $journalDirectory -ErrorAction Stop | Out-Null

function Invoke-PnpLogged {
    param([Parameter(Mandatory)][string[]]$Arguments)

    "`r`n> pnputil $($Arguments -join ' ')" |
        Out-File -LiteralPath $transcript -Append -Encoding utf8
    & $pnp @Arguments 2>&1 |
        Tee-Object -FilePath $transcript -Append
    $exitCode = $LASTEXITCODE
    "Exit code: $exitCode" |
        Out-File -LiteralPath $transcript -Append -Encoding utf8
    if ($exitCode -ne 0) {
        throw "PnPUtil failed with exit code $exitCode."
    }
}
```

Сначала подготовьте все пять подписанных пакетов без привязки к устройствам:

```powershell
Invoke-PnpLogged @('/add-driver', "$packageRoot\rzdevu_02e0_vcon\rzdevu_02e0_vcon.inf")
Invoke-PnpLogged @('/add-driver', "$packageRoot\rzcommonu\rzcommonu.inf")
Invoke-PnpLogged @('/add-driver', "$packageRoot\rzdevu_02e0_dkm\rzdevu_02e0_dkm.inf")
Invoke-PnpLogged @('/add-driver', "$packageRoot\rzdevu_02e0_kbd\rzdevu_02e0_kbd.inf")
Invoke-PnpLogged @('/add-driver', "$packageRoot\rzdevu_02e0_mou\rzdevu_02e0_mou.inf")
```

После каждой команды скопируйте в журнал новое опубликованное имя и идентичность
пакета. Отметьте, присутствовал ли он в перечне до установки. Это подтверждение владения,
которое используется при откате.

После успешной подготовки всех пяти пакетов привяжите их в порядке зависимостей:

```powershell
Invoke-PnpLogged @('/add-driver', "$packageRoot\rzdevu_02e0_dkm\rzdevu_02e0_dkm.inf", '/install')
Invoke-PnpLogged @('/add-driver', "$packageRoot\rzdevu_02e0_vcon\rzdevu_02e0_vcon.inf", '/install')
Invoke-PnpLogged @('/add-driver', "$packageRoot\rzdevu_02e0_kbd\rzdevu_02e0_kbd.inf", '/install')
Invoke-PnpLogged @('/add-driver', "$packageRoot\rzdevu_02e0_mou\rzdevu_02e0_mou.inf", '/install')
Invoke-PnpLogged @('/add-driver', "$packageRoot\rzcommonu\rzcommonu.inf", '/install')
```

Во время проверки не добавляйте `/reboot` к этим командам. Если Windows запросит
перезапуск, остановитесь и выполните запланированную перезагрузку после надёжного
сохранения журнала. PnPUtil не устанавливает на устройство драйвер с более низким
рангом принудительно, поэтому нулевой код завершения не заменяет проверку после установки.

После установки проверьте точные дочерние элементы `RZVIRTUAL` и `RZCONTROL`, их службы
и стеки, а также отсутствие проблем в Диспетчере устройств. Перезапустите OpenBlade и
откройте «О программе» > «Сведения об устройстве». В строке драйвера яркости Razer должно
быть указано `Available · Windows OSD` (в русском интерфейсе — «Доступно · системный
индикатор Windows»). Проверьте нажатие, удержание и отпускание клавиши яркости на ноутбуке:
яркость должна меняться, а Windows — показывать своё всплывающее окно.

Не удаляйте устройства массово, не используйте `/force` или команды перезапуска всего
класса. При откате можно удалять только опубликованные пакеты, которые, согласно
сохранённому журналу до установки, были добавлены этим испытанием. Удаляйте эти пакеты
в следующем порядке: RzCommon, VCon, мышь, клавиатура, затем DKM. Используйте
`pnputil /delete-driver <journal-owned-oem.inf> /uninstall` и остановитесь, если Windows
сообщит, что пакет используется или требуется перезагрузка.

До публикации установщика с одним действием проверьте две чистые установки RZ09-0581,
восстановление после сбоя на каждом пакете, обратный откат с восстановлением встроенной
клавиатуры и сенсорной панели, идемпотентное восстановление, циклы перезагрузки и сна,
а также работу удержания и отпускания клавиши яркости на ноутбуке. Пока эти проверки не
пройдены, используйте штатные команды только в рамках контролируемой проверки.

Экспортированные файлы остаются собственностью Razer и не покрываются лицензией GPL
OpenBlade. Перед добавлением архива в общедоступный выпуск сохраните письменное
разрешение Razer, охватывающее точные файлы и способ распространения, и поставляйте
`THIRD-PARTY-NOTICE.txt` архива без изменений.
